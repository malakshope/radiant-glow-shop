# Radiant Glow Shop

Create a modern, luxurious, and fully responsive e-commerce website for a skincare brand specializing in serums, face creams, moisturizers, cleansers, and sunscreen.



Design Style:

- Elegant, premium beauty aesthetic.

- Soft colors: white, beige, light pink, cream, and light green.

- Rounded corners with subtle shadows.

- Smooth animations and professional transitions.

- Mobile-first responsive design.



Homepage:

- Large hero banner with beautiful skincare products.

- Headline: "Healthy Skin Starts Here."

- Subtitle promoting radiant, hydrated, and protected skin.

- "Shop Now" button.

- Featured product categories:

  - Serums

  - Face Creams

  - Moisturizers

  - Cleansers

  - Sunscreens

- Best Sellers section.

- New Arrivals section.

- Customer Reviews.

- Benefits section with icons:

  - Dermatologically Tested

  - Fast Delivery

  - Secure Payment

  - Premium Quality

- Newsletter subscription.

- Elegant footer with social media links.



Product Page:

- Large product images with gallery.

- Product name.

- Price.

- Product description.

- Skin type compatibility.

- Key ingredients.

- Benefits.

- How to use.

- Quantity selector.

- Add to Cart button.

- Buy Now button.

- Related products.

- Customer reviews.



Shopping Cart:

- Update quantity.

- Remove products.

- Order summary.

- Delivery cost.

- Total price.

- Checkout button.



Checkout:

- Full name.

- Phone number.

- Wilaya.

- Address.

- Order summary.

- Confirm Order button.



Admin Dashboard:

- Login page.

- Add/Edit/Delete products.

- Upload multiple product images.

- Manage categories.

- Manage orders.

- Change order status:

  Pending

  Confirmed

  Shipped

  Delivered

  Cancelled

- Sales statistics dashboard.

- Search and filter orders.

- Customer management.



Extra Features:

- Product search.

- Filters by category.

- Filters by skin type:

  Oily

  Dry

  Combination

  Sensitive

- Wishlist.

- Discount coupons.

- Dark mode.

- SEO optimized.

- Fast loading.

- Professional animations.

- Clean and luxurious UI.
